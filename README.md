# Документ для тех, кто готов создать новую статью

Проще всего взять статью с похожего здания и сделать новую на её основе. 

## Структура статьи
Каждая статья должна иметь свою структуру:
1. Заголовок
2. Инфобокс с фотографией
3. Краткая биография
4. Оглавление (`[[toc]]`)
5. Описание
6. Лор
7. Интересные факты
8. Галерея
9. Воспоминания
10. Правки пользователей
11. Дата последнего обновления и авторство

## Классы страниц (pageClass)
Каждый заголовок имеет свой класс:
*   `destroyed` — красное свечение для исчезнувшего слоя
*   `com` — жёлтое свечение для нежилых зданий
*   `alive` — зелёное свечение для жилых домов
*   `dead` — серое свечение для заброшенных, служебных, нереализованных или неподтверждённых зданий

## Фото
Фото для инфобокса и галереи берутся из встроенной библиотеки `public`. 
Нужные фото находятся по пути: `/AAB/BCD.jpg`
*   `AA`, `BB` и `C` берутся с адреса статьи
*   `D` — номер фото.

Если нужные фото не найдены, в инфобокс ставится заглушка `NA.jpg`, а галерея сжимается до фразы: *(фото будут добавлены позже)*.

## Правила заполнения разделов
*   **Краткая биография:** Описывает здание в двух словах, указывает на его местоположение относительно соседних объектов. Под ней ставится `[[toc]]`.
*   **Описание:** Всё, что связано с внешностью здания.
*   **Лор:** Про жизнь здания. История строительства, ремонта, расселение, инциденты, всё это пишется здесь.
*   **Интересные факты:** Всякие важные мелочи, не получившие места в других частях статьи.
*   **Галерея:** Лучше не трогать без опыта, так как для каждой фотографии нужен примерный год её создания и, возможно, ссылка на автора.
*   **Воспоминания:** Можно сразу добавить своё.
*   **Конец статьи:** Без правок пользователей стоит заглушка *«Статья ждёт первую правку...»* и ссылка на редактирование. Последняя строка посвящена дате последнего обновления и автору.

## Ссылка
При создании статьи на GitHub каждая статья должна получить свою уникальную ссылку вида:
`https://neru-wiki.github.io/main/AA/BBC.html`

Где:
*   **AA** — ID улицы, на которой расположен объект.
*   **BB** — Номер дома без дроби. Все однозначные номера пишутся с ведущим нулём, например: `09`.
*   **C** — Обычно используется, как номер дроби без ведущих нулей. В тех случаях, когда два объекта имеют один адрес в разное время, значение `C = 9 - (номер дроби)`. Если постройка не имеет точного адреса, получила трёхзначный номер дома или двухзначный номер дроби, вместо `C` могут использоваться латинские заглавные буквы.

**Примеры ссылок:**
*   `https://neru-wiki.github.io/main/03/150.html` — пр. Геологов 15
*   `https://neru-wiki.github.io/main/02/041.html` — ул. Южно-Якутская 4/1
*   `https://neru-wiki.github.io/main/01/081.html` — ул. Чурапчинская 8/1 (исчезнувший слой)
*   `https://neru-wiki.github.io/main/01/088.html` — ул. Чурапчинская 8/1 (актуальный слой)
