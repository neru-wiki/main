# ул. Южно-Якутская

**Южно-Якутская** - улица города Нерюнгри. 
Относилась к улицам деревянной застройки. 
Народное название - ЮЯ.

## **Описание**
**Южно-Якутская** стартует на перекрёстке с Геологов в виде проспекта. 
Рядом со стоматологической поликлиникой совершает очень плавный поворот направо. 
Ещё один плавный поворот, уже налево, идёт после перекрёстка с Кравченко. Здесь же дорога сужается.
Улица идёт строго на юг, пересекая Дружбы Народов и завершаясь на Мира. 

Автобусные остановки: Стоматология -> Театр -> Институт -> Находка -> Нерюнгрибанк -> Реабилитационный Центр -> Каскад. 

## **Лор**
Раньше нумерация зданий была принципиально иной. Дом №16 имел номер 41, а №14 - 39. 
Остальные детали той нумерации неизвестны. Возможно, улица носила другое название в первые годы жизни. 

Стройка дороги шла с 1977 до конца восьмидесятых. 

Первая половина улицы посвящена деревянной застройке. Эта часть практически вымерла. Жителей минимум. Деревяшек осталось не больше 3.

Вторая половина принадлежит действующим кварталам каменной застройки. 

## **Интересные факты**
Единственная улица, название которой пишется с дефисом. 

Все улицы узкие, проспекты широкие. Уникальный случай: **Южно-Якутская** совмещает оба этих варианта в себе.
