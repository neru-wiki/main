# 2B

**2B** - один из проектов жилых деревянных домов города Нерюнгри. Настоящее название: **111-115-86СМ**. Дома с таким проектом назывались **щитовиками**.

## **Описание**
Такие дома строились из щитовых панелей. Фасад обшивался слоем досок. 

Окна узкие, форточки обычно расположены слева.

Все дома с таким проектом имеют по 2 этажа и 2 подъезда. В каждом подъезде обычно по 8 квартир. Первый подъезд всегда является ревёрсом второго. 

Первый этаж идентичен второму, за исключением лоджии прямо над входом. Помещение с этой лоджией - комната одной из квартир, либо отдельная жилая колясочная. 

Над лоджиями второго этажа имеются треугольные фронтоны: маленькие для одиночных, большие для сдвоенных. 

Лоджии по бокам подъездной стороны обычно встроены во внутрь фасада и не имеют фронтонов. 

Крыша двускатная, всегда содержит один выход с тыльной стороны дома, на фронтонах обычно по три форточки.  

## **Лор**
Проект встречается в других северных и дальневосточных регионах России. Например, в городе Ноябрьск (ЯМАО). 

В 1979, после постройки экспериментального Геологов 45 проект стал типовым.

К 1986 возведение таких домов прекратилось. Последний деревянный дом в Нерюнгри был построен по этому проекту. Всего было построено 51-52 таких дома.

Щитовики становились аварийными уже спустя 20-25 лет после постройки. 

В городе остался всего один представитель данного проекта - Геологов 47, остальные ликвидированы до 2022.
