## **Описание**
**2E** строились из бруса. Фасад обшивался слоем досок. Общаги рассчитаны на 100 человек.  

Окна в основном широкие, но есть и секции с узкими. Форточки обычно расположены слева. На торцах по два окна. Балконы отсутствуют.  

Все **2E** имеют по 2 этажа. Главный вход по умолчанию выпирает, как пристройка. Ещё два запасных входа стоят с другой стороны дома. 
Первый этаж идентичен второму, за исключением помещением с окном прямо над входом. При игнорировании главного входа **2E** симметричен по оси X.  

Крыша обычно вальмовая, содержит по два выхода спереди и сзади. 

## **Лор**
**2E** встречается в других северных и дальневосточных регионах России. Например, в соседнем посёлке Серебряный Бор. 

Возводились дома по этому проекту с 1978 по 1982, всего их было построено 15. 
ТРИНАДЦАТЬ из них сгорели очень давно и почти [забыты](https://docs.google.com/document/d/1ECdrnax77hPcHNvgaEy6ywCUl9K5NRtyRBhKjSXMumE).

В городе остался всего один представитель данного проекта - Чурапчинская 7.

## **Интересные факты**
**2E** сгорали дотла в 13 раз чаще, чем признавались аварийными. 87% зданий **2E** уничтожены огнём - самый высокий процент среди всех проектов Нерюнгри.
